### 2. **Add Resource Scarcity**
- ✅ Current: Unlimited resources
- ❌ Problem: Building is meaningless
- ✅ Fix: Finite resource pools

**In `world/simulation.py`:**
```python
class World:
    def __init__(self):
        # FINITE RESOURCE POOLS
        self.resource_pools = {
            'stone': 500,  # Total available in world
            'wood': 300,
            'clay': 200,
            'metal_ore': 0,  # Unlocked after fire
            'iron_ore': 0,   # Unlocked after bronze
        }

    def gather_resource(self, resource_type, amount):
        if self.resource_pools[resource_type] >= amount:
            self.resource_pools[resource_type] -= amount
            return SUCCESS
        else:
            return FAILURE - "Resource depleted!"
```

```python
def calculate_building_cost(purpose, era):
    base_costs = {
        'shelter': {'stone': 20, 'wood': 10},
        'storage': {'wood': 30},
        'workshop': {'stone': 50, 'wood': 30}
    }

    # Multiply by production multiplier (inverse)
    mult = civilization_progression.get_production_multiplier()
    effective_cost = {mat: int(cost / mult) for mat, cost in base_costs[purpose].items()}

    return effective_cost
```
