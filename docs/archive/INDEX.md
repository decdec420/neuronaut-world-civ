**Search by keyword:**
```bash

# Search just titles

```

**Common searches:**
- "refactoring" → `/refactoring/`
- "AI" or "autonomy" → `/ai-autonomy/`
- "deployment" → `/deployment/`
- "architecture" → `/architecture/`
