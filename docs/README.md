# Docs

The current documentation is:

- [README.md](../README.md): what the sim is, how to run it, its settings, deployment
- [CLAUDE.md](../CLAUDE.md): how the code is laid out, how to verify a change, known open issues
- [AUDIT.md](../AUDIT.md): the audit of 2026-11-22 (a snapshot; most of what it found has since been fixed)

`references/` holds the original design PDFs.

`archive/` holds about a hundred older reports, plans and guides written while
the project was being built. They are kept for history only: many describe
systems as "complete" that were broken at the time, and much has changed
since. Don't rely on them; check the code (and `scripts/sim_check.py`).
