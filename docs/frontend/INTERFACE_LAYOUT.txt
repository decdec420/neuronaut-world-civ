                           VISUAL LEGEND
═══════════════════════════════════════════════════════════════════════════════════

AGENT SPRITES:
  👨 = Male (Blue)    👩 = Female (Pink)    🧑 = Non-binary (Purple)

MOOD INDICATORS:
  Green glow 🟢 = Happy        Yellow glow 🟡 = Neutral      Red glow 🔴 = Sad

TERRAIN TYPES:
  ░░ = Grass          🌲 = Forest          ~~ = Water          ▓▓ = Mountain

RESOURCES:
  🌲 = Wood    🪨 = Stone    🌾 = Food    💰 = Gold    ⚙️ = Iron    💧 = Water

BUILDINGS:
  🏠 = Home    🌾 = Farm    🔨 = Workshop    🏪 = Market    📚 = Library

STATUS BARS:
  ▓▓▓▓ = Full/High     ▓▓░░ = Medium      ▓░░░ = Low       ░░░░ = Empty
