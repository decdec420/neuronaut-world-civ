## 🔧 How To Use

### **Run Full Simulation**

```bash
# Start server
python main.py

# Access:
http://localhost:8000/app      # Web interface (when rebuilt)
http://localhost:8000/docs      # API documentation
```

### **Configure AI Behavior**

Edit `.env`:
```bash
# Enable/disable AI
USE_LLM_DECISIONS=true

# Planning frequency
LONG_TERM_PLANNING_INTERVAL=100  # ticks

# Reflection frequency
REFLECTION_INTERVAL=500          # ticks

# API Keys (optional)
GROQ_API_KEY=your_key_here
GEMINI_API_KEY=your_key_here
# Or just use Ollama (unlimited!)
```

### **Run Tests**

```bash
# Test LLM providers
python test_autonomous_agents.py

# Test full integration
python test_simulation_integration.py

# Test consequence learning
python test_consequences.py
```
